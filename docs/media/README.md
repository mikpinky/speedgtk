# Media assets

This directory contains the images and short demos shown in the project README.

Use these names so the README can be updated without changing its structure:

- `download-demo.mp4` — short live-download demonstration.
- `upload-demo.mp4` — short live-upload demonstration.
- `main-window-at-launch.png` — SpeedGTK at launch.
- `test-complete-main-windows.png` — completed test view.
- `history.png` — history dialog.

For demos, use MP4 with the H.264 video codec. Keep each video short and
compressed for web viewing. Use PNG for screenshots; it preserves the sharp
text and GTK interface details.
